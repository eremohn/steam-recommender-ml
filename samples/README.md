# Samples

Esta carpeta contiene archivos CSV con datos de ejemplo extraídos del dataset principal del proyecto.

Estos archivos están diseñados para que cualquier usuario pueda probar los endpoints de la API con valores válidos y reales.

## Archivos disponibles

- `unique_app_names.csv`: Lista de títulos únicos de juegos (`app_name`)
- `unique_developer.csv`: Lista de desarrolladores únicos (`developer`)
- `unique_publisher.csv`: Lista de publishers únicos (`publisher`)

## Uso sugerido

Utiliza estos archivos para:

- Buscar nombres de juegos válidos al testear la API.
- Obtener valores reales para los parámetros requeridos.
- Realizar pruebas sin necesidad de inspeccionar el dataset completo.

> ⚠️ Nota: Estos archivos **no son parte del flujo de datos del modelo ni del ETL**, y están destinados exclusivamente a pruebas manuales.
